# ADR-004 — Session Host owns persistent terminal lifetime

Status: Accepted  
Date: 2026-09-21

## Decision
Persistent tmux/session ownership is separated from short-lived MCP/Agent request lifecycle.

## Reason
API restart/update must not implicitly terminate long-running terminal work.

## Consequences
Use an explicit Session Host lifecycle and tmux socket; prove behavior under systemd. Updates/uninstall require a live-session policy.
