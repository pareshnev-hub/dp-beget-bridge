# ADR-003 — Session and Operation are separate state machines

Status: Accepted  
Date: 2026-09-21

## Decision
A terminal Session persists independently of individual managed Operations. Operations receive durable IDs, idempotency semantics and honest UNKNOWN outcomes.

## Reason
MCP/request timeouts and transport retries must not kill sessions or silently duplicate shell side effects.

## Consequences
One writer per session. Completion status is not inferred solely from PTY stdout. Arbitrary shell commands are not advertised as exactly-once.
