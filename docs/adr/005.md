# ADR-005 — Direct authorization is local to the user VPS

Status: Accepted  
Date: 2026-09-21

## Decision
Target Direct authorization uses a local OAuth/OIDC-compatible adapter on the user's VPS with PKCE, resource/audience checks, consent, revoke and re-pair.

## Reason
Direct must continue working without a DP central control service.

## Consequences
Client-registration mode is proven against the actual client. Model-supplied confirmation is never treated as human approval.
