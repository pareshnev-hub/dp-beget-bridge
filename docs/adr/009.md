# ADR-009 — Catalog is optional transport over shared capabilities

Status: Accepted  
Date: 2026-09-21

## Decision
A future Catalog path reuses the same terminal/file capability core. A Relay is built only after verifying current distribution requirements.

## Reason
Duplicating execution logic creates security drift and premature central infrastructure.

## Consequences
Direct remains independent. Device identity is cryptographic, not MAC-based. Relay does not durably store data-plane bodies.
