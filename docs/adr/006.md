# ADR-006 — Separate runtime identities and service secrets

Status: Accepted  
Date: 2026-09-21

## Decision
MCP/auth, Agent/policy and restricted work execution use separate OS identities/ACLs or an equivalent proven boundary. Root is not the default runtime.

## Reason
Removing secrets from environment variables is insufficient if shell tasks can read the same secret files.

## Consequences
Installer/service layout becomes more explicit. A true host-root execution profile changes the trust boundary and must be disclosed separately.
