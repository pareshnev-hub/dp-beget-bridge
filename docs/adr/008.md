# ADR-008 — Product telemetry is opt-in and non-blocking

Status: Accepted  
Date: 2026-09-21

## Decision
Telemetry is disabled by default, strict-allowlist, coarse and outside the execution path.

## Reason
Product analytics must not become centralized session surveillance or a runtime dependency.

## Consequences
Meaningful terminal/file actions define active usage. Installation counts are not exact people. Collector failure cannot block Direct.
