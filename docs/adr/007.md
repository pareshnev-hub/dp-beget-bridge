# ADR-007 — Disable unsafe file mutations rather than weaken semantics

Status: Accepted  
Date: 2026-09-21

## Decision
File operations that cannot yet be implemented with safe overwrite/race/symlink semantics return an explicit unsupported error.

## Reason
A smaller safe capability set is preferable to silent data loss or security theater.

## Consequences
No destination pre-delete. Complex EXDEV/directory replacement and recursive cases remain disabled until journaled and tested.
