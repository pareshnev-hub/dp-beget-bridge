# ADR-002 — Linux VPS is the current platform boundary

Status: Accepted  
Date: 2026-09-21

## Decision
The current product targets Linux VPS with systemd/tmux. Windows Agent/UAC/desktop-control architecture is outside scope.

## Reason
The repository and product problem are Beget/Linux terminal and file access.

## Consequences
Do not add Windows/NAT/GUI requirements to MVP. Additional OS support is a later capability requiring its own ADR.
