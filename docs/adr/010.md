# ADR-010 — Direct transactional metadata uses local embedded state

Status: Accepted  
Date: 2026-09-21

## Decision
Use an embedded transactional state adapter, targeted at SQLite, for sessions/operations/grants/migrations. Transcript bodies remain local files.

## Reason
Single-owner Direct installations do not justify per-VPS Postgres/Redis, while flat JSON is weak for operation/grant transactions.

## Consequences
The exact driver is selected in an implementation compatibility PR. Schema migrations are versioned and rollback-aware.
