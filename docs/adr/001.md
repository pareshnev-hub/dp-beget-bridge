# ADR-001 — Direct Mode is primary and autonomous

Status: Accepted  
Date: 2026-09-21

## Decision
Installed Direct Mode runs between the MCP client and the user's VPS. DP website, telemetry, feedback and Catalog infrastructure are not required for execution.

## Reason
Privacy, autonomy and fault containment are core product requirements.

## Consequences
Local auth/state must be sufficient for operation. Central outages cannot revoke or stop an already-authorized Direct runtime. Catalog is additive.
