# ADR-011 — Public releases use immutable verified artifacts

Status: Accepted  
Date: 2026-09-21

## Decision
Public installation/update uses immutable versioned artifacts with digest/signature verification, staged activation, health checks and rollback.

## Reason
Installing mutable main or executing unverified updates creates supply-chain and recovery risk.

## Consequences
BUILD, RELEASE and DEPLOYMENT are distinct. Live Session Host state is not implicitly destroyed during service update.
