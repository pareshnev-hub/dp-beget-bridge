# ADR-012 — Scale by measured workload

Status: Accepted  
Date: 2026-09-21

## Decision
Do not add Redis, brokers, Kubernetes or multi-region infrastructure solely because future installation counts may be high.

## Reason
Direct runtime is naturally distributed across user VPSs. Central scale depends on actual Relay/telemetry/feedback load.

## Consequences
Measure active tunnels, requests/sec, bytes/sec, concurrent operations, RSS, FDs, queue depth and latency before adding horizontal coordination infrastructure.
