# Feedback

The product page may offer a short voluntary form with:

- message (required);
- reply email (optional);
- name and country (optional);
- DP version and anonymous installation ID (optional, prefilled only with
  consent);
- explicit checkbox to attach diagnostic metadata.

Diagnostic metadata never includes commands, output, paths, filenames, file
content, tokens, or credentials. The form must show retention time and a
deletion contact before submission. GitHub Issues remain the public alternative.
