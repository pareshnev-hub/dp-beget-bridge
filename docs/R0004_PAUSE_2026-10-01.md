## Ограничения доказанных результатов

- Положительный запуск защищённой команды на чистом публичном сервере с настоящими DNS/сертификатом и последующее подключение клиента ещё не приняты.
- Изолированное Caddy-окружение намеренно отклоняется проверкой начального сетевого пространства сервера. Запуск приложения внутри тестового окружения использует явно внедрённую тестовую проверку.
- Локальная OAuth-проверка использует синтетическое согласие владельца. Проверка загрузки файла идёт через локальный Agent с синтетическим OAuth-контекстом; это не доказательство внешней загрузки вложения через настоящий клиент.
- Существующий Beget с N8N/Traefik/R03 не является чистой целевой площадкой. Эти проверки не разрешают заменять его окружение.

## Незавершённые изменения, сохранённые как WIP

Изменены только:

1. `scripts/integration/clean-private-autonomy.mjs`.
2. `test/release-real-clean-private-install.test.js`.

Добавлена ещё не проверенная на целевом Linux последовательность: отказ архивирования/очистки активного терминала; сохранение закрытого терминала после перезапуска Session Host; создание и проверка приватного архива от имени рабочего пользователя; очистка исходной сессии с сохранением архива и приватного контрольного файла. В проверку установки добавлены ожидания соответствующих результатов.

**Эта версия WIP не проходила CI и не должна считаться готовой. PR для неё не создан; в main она не слита.** Локальный запуск архивных тестов на macOS дал три ошибки из-за канонизации временных путей; защитная проверка тестового окружения прошла. Последние правки после этого не проверялись.

После разрешения возобновить следует сначала проверить Linux-последовательность, в особенности реальное сообщение отказа очистки активной сессии, завершение записи вывода перед сравнением курсоров, права приватной папки архива и сохранение данных после перезапуска. Затем отдельно оценить результат; не засчитывать существование тестовых ожиданий как пройденную приёмку. Безопасное удаление/сброс окружения этими изменениями не реализованы.

## Что ещё открыто до R04 / 1.0.0

Все семь крупных блоков приёмки в #87 остаются открытыми:

4. Хранение, квоты, архивирование, свободное место, безопасное удаление/сброс и политика активных сессий.
5. Формальная автономность AUTO-01…04 через настоящий клиент и связка N/N−1; телеметрия OFF уже принята.
6. Матрица поддерживаемых платформ и восстановления, документация, приватность, поддержка, release notes и независимая проверка безопасности.

Обоснованного процента готовности и подтверждённого срока завершения сейчас нет. Число слитых PR не является процентом выполнения этих блоков.
